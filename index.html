Why & how

Written by students, built like software

Innovation Earth Projects is a student-run studio that builds free, private, zero-friction tools for learners. The research division writes about what we learn while building those tools: education-technology friction, privacy-by-design for minors, and what actually works when teenagers ship real software.

Every paper follows the same four rules the project itself runs on: free where it counts (no paywalls, ever), private by default (this site sets no cookies and runs no analytics beyond fonts), zero friction (a download is one click, no account), and built from real problems (we only write about things we've hit ourselves).

Papers are plain Markdown files in a public repository, compiled by one auditable build script into this site's pages and PDFs. That means every claim on this site can be traced back to a text file — a nice property for research, and an even nicer one if you're curious how it works.

Citing: each paper carries a stable identifier (for example IEP-2026.0001) shown on its download row and inside the PDF. Cite the PDF version and the identifier; there's no DOI yet, and we say so honestly rather than pretending otherwise.

How a paper gets on the download list

Plain files, one build script — everything is auditable.

  1. Write the paper as Markdown. Create papers/<id>.md with a # Title, a ## Abstract section, and the body. That file is the single editable source of truth.
  2. Add it to the catalog. One entry in js/papers-data.json — title, authors, summary, category, keywords, date, version, pages.
  3. Run the build. python3 build.py generates the reading page, the PDF, the Markdown copy, the ZIP bundle, and refreshes papers/feed.json. Both pages read from that feed automatically — no HTML edits needed.
  4. Push to GitHub — GitHub Pages serves the updated download list automatically.
