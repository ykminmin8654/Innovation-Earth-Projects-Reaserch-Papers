How a paper gets on this page

Plain files, one build script — everything is auditable.

  1. Write the paper as Markdown. Create papers/<id>.md in this repository with a # Title, a ## Abstract section, and the body. That file is the single editable source of truth.
  2. Add it to the catalog. Add one entry for the new paper in js/papers-data.json — title, authors, summary, category, keywords, date, version, pages.
  3. Run the build. python3 build.py generates the styled preprint page (papers/<id>.html), the PDF download (downloads/<id>.pdf), the Markdown copy, downloads/all-papers.zip, and refreshes papers/feed.json.
  4. Push to GitHub — GitHub Pages serves the updated library automatically.
