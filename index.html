For authors

How a paper gets on this page

Same admin as the main website — one key, one login.

  1. Publish from the admin panel. Open admin.html on this site (or innovationearthprojects.org/admin/) and unlock with the shared IEP admin key. Click ＋ New paper, fill in title, authors, summary, category and body, then Save & publish. It commits Markdown straight into papers/data/<slug>.md in this repository.
  2. The build runs itself. A GitHub Action watches papers/: it runs build.py, which generates the styled preprint page, the PDF download, and refreshes papers/feed.json and downloads/all-papers.zip. Live in about two minutes.
  3. (Optional) hand-write instead. Prefer editing files? Drop papers/<id>.md plus one entry in js/papers-data.json and run python3 build.py yourself — both paths produce the same output.
  4. Push to GitHub — GitHub Pages serves the updated library automatically.
